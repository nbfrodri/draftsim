# DraftSim v1.13.0

The Event Statistics selectors now use themed dropdowns with region, split and event logos instead of the system select menus.

- **Event** groups the season's events by phase, with the region logo and name for each league and the split or tournament icon in the group header. The selected event shows its full name.
- **Stage**, **Evolution** and **Sort** share the same dropdown. Evolution lists the number of games next to each checkpoint and separates Play-in from Main event checkpoints when both exist.
- Event Statistics headers, including archived seasons, show the region logo next to the split icon.
- The popup is wider so long labels are not cut off, opens upwards when there is no room below, supports keyboard navigation and typing, and Escape closes only the open dropdown.

No save or schema change: existing realities and archives open as before, and no SQLite migration is required.

Local verification: TypeScript, ESLint, the unit suite, the production export and the affected browser tests passed. The tagged workflow additionally runs the full browser suite and Windows/Linux installer checks before publishing NSIS, MSI, deb, rpm and AppImage packages.
