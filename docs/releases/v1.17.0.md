# DraftSim v1.17.0

Compressed reality exports, plus card and bulk statistics fixes.

## Compressed exports (desktop)

- **New option: Compress exports.** In the Realities hub (and under the bulk "Export reality backup" option) you can choose to save reality exports as `.draftsim-reality.json.gz`. They contain exactly the same data as the `.json` export and are several times smaller; the in-app database is already compressed the same way since storage format 9, which is why it is much smaller than a plain JSON export.
- Importing accepts both `.json` and `.json.gz`; compressed files are recognised by their content. Older DraftSim versions cannot import compressed exports.
- Note: very long realities (hundreds of MB of history) still cannot be imported back in one piece, compressed or not; exporting them works.

## Fixes

- The SS tier in player cards and team panels uses the same badge size as every other tier.
- Bulk event statistics: each role shows its icon, the leader, the team logo and name, and the score in an aligned column; nothing is truncated (long names wrap), and the per-player region mark was removed.

No save or schema change.
