# DraftSim v1.3.0

## Shared teammate rosters and results

- Expand **Most frequent teammates** in a player profile to see each shared year's titles, Timeline shortcut and recorded splits/international events.
- Each event shows the historical club, region, saved logo and finish, including champion, runner-up and recorded play-in exits.
- Expand an event to inspect the full captured lineup by position, with tiers, recorded ages and coach. Player/team cards retain the archived season and event context. **Close roster** returns focus to that event's summary.
- Within-year transfers preserve the lineup and club from each shared phase. Stable player IDs and team name plus region keep same-named players or clubs separate. Repeated event snapshots and duplicate archive revisions do not inflate shared counts.
- International clubs without participation evidence in a retained full placement list are excluded. Older snapshots with unknown results show **Placement unavailable**. Missing identities and rosters are not reconstructed from current teams.

The profile reads existing phase snapshots and requires no save migration. See the [shared career guide](../title-playground.md#shared-career-history) and [domain contracts](../domain-contracts.md#compañeros-rosters-compartidos-y-resultados).

## Dependency maintenance

The release lockfile updates Next.js to 16.3.8 and the affected `brace-expansion` dependencies to compatible patched versions. The dependency audit reported zero vulnerabilities when this release was validated.
