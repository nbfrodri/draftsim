# DraftSim v1.9.1

## SS Race presentation

- SS Race starts collapsed, matching the neighboring season panels. Expand or minimize it with the header button, mouse or keyboard; the selected role survives reopening.
- The header shows occupied SS seats without computing projections. Closed panels do not mount or recalculate the live race.
- Neutral surfaces, gold controls and compact Inter typography match the dashboard. Cyan remains on the SS badge.
- Role cards show current holders; ranked comparison rows show contenders, grades, gold differences, win rates, rated games and estimated chances. Empty seats are compact, long names fit, and the layout adapts to narrow widths.
- Selection rules remain in a disclosure. SS eligibility, scoring, estimated chances and phase-boundary awards are unchanged.

## Documentation

Both READMEs now contain a short overview, downloads, essential commands and documentation links. Detailed Windows/Linux installation, update instructions, FUSE troubleshooting and the Omarchy native-build fallback live in separate [English](../installation.md) and [Spanish](../installation.es.md) guides. The documentation index includes v1.8.0 and v1.9.0, and obsolete architecture anchors are corrected.

## Compatibility and verification

Existing realities and saves remain compatible; there is no schema migration. Panel state is local to the interface.

Local checks passed TypeScript, changed-file lint, the production static export, 28 focused SS/persistence tests and three browser checks. The SS browser scenario exercises collapse/reopen, keyboard controls, retained role selection, seven contenders, long names and mobile overflow. Screenshots were visually reviewed. Changed-file `aislop` scanning reported no warnings or errors.

The release workflow separately validates the tagged revision, runs the complete unit/browser suites and native checks, and publishes NSIS, MSI, deb, rpm and AppImage packages only after its checks pass.
