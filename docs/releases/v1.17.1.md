# DraftSim v1.17.1

Long realities can be imported again, plus two reliability fixes.

## Import

- **Reality files are imported in parts.** A long reality's export can be larger than the longest text the engine can hold, so importing it failed. Files (`.json` or `.json.gz`) are now read and checked one archived year at a time, with the same validation as before applied to every part and size limits per year (up to 2 GiB in total). A 57-year reality exported to a 503 MB file (82 MB compressed) imports back unchanged.
- REAL1 share codes keep their own size limit.

## Fixes

- Stored player chemistry never keeps a "negative zero", so a save reloads exactly equal (this made a rare test failure).
- The Windows native check waits long enough for a reality to open on a cold machine.

No save or schema change.
