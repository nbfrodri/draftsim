# DraftSim v1.15.2

Lighter saves of the season being played.

## Saves

- **Each played match's lineups no longer repeat the same synergy data.** Every series keeps both lineups as they were at that match, and each player's champion synergy map (about 1 KB) was copied into every match. Each distinct map is now saved once and the matches point to it; loading restores every lineup exactly. In a long reality measured mid-year, the saved season went from 27.5 MB to 17.5 MB (31.8 MB before v1.15.1).
- Older saves open as before, with no migration. If a referenced synergy were ever missing, loading stops without overwriting the save.
- Opening this save with an older version keeps lineups, results and statistics; only the synergy of matches already played in the current season would be missing.

Not yet verified on Windows WebView2.
