# DraftSim v1.16.1

Fixes found while upgrading a long reality to storage format 9, plus bulk statistics polish.

## Fixes

- **Startup no longer gives up during a long upgrade.** The loading screen used to declare a failure after 45 seconds, even while the one-time format 9 upgrade was still converting years (a Retry then finished it). It now waits as long as loading keeps reporting progress, allows long single steps such as the recovery copy and compaction, and shows the current step (for example "Optimizing saved history (12 of 57 years)").
- **Exporting a long reality no longer fails with "Invalid string length".** Exports were built as one text before writing, and a long reality can exceed the largest text the engine allows. They are now written one archived year at a time (bulk end-of-run export and both Export buttons), with the same file format. If an export still fails, the bulk panel says the simulation was saved and only the export file could not be written.
- The champion statistics "Show" selector is aligned with the role filters.

## Bulk simulation

- Event statistics in the bulk results show team logos, and player and team names open their cards.

No save or schema change.
