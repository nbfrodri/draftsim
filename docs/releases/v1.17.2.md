# DraftSim v1.17.2

Two interface fixes.

## Fixes

- **The bulk results window no longer follows later simulations.** After a bulk years run, simulating a match, matchday, tournament or season opened the wide window with the old "Live Results" feed. The live feed now shows in the simulation window only during bulk years; the dashboard results panel stays until dismissed.
- **SS players show the SS badge** instead of plain text in the Hall player search, the live "Find a player" search and Season History (International Champions, team rosters, transfers, potential, player profile and career timeline).

No save or schema change.
