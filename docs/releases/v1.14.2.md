# DraftSim v1.14.2

Bulk simulation changes aimed at the blank window on Windows, plus SS badge, tier chip and role leader layout fixes.

## Bulk simulation on Windows

- **The reality is exported once, at the end.** The optional export file used to rebuild the whole reality as one JSON string after every simulated year, which raised the JavaScript heap by more than 1 GB each time. It now runs once when the bulk run ends, including after a cancel, and is skipped if the memory guard stopped the run.
- **No second bulk run can start on top of the final save.** The bulk now stays busy until its last save finishes.
- **Hiding the window no longer writes the live season.** Minimising or switching away during a bulk run used to flush the held mid-year snapshot (up to 52 MB); closing or unloading still saves.
- Not yet verified on Windows WebView2. If the window still goes blank, `bulk-diagnostics.log` shows the year and stage.

## Interface

- The SS badge appears only where SS is a value or status (holders, Gained/Retained/Lost chips, timelines, hover cards); titles and prose use plain text.
- Tier chips such as "SS" and "S+" fit without clipping, also in the bulk results feed.
- Role leaders in Event Statistics use a responsive grid instead of a single stack.

## Maintenance

- The development-only dependency audit exception now expires on 2026-12-03.

No save or schema change: existing realities and archives open as before.
