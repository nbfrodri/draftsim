# DraftSim v1.16.0

Much smaller saves and faster startup for long realities.

## Storage format 9

- **Archived years are stored compressed.** Each year is saved deflate-compressed (5-7x smaller) and still validated as JSON by backups.
- **Event statistics load when you open them.** The per-event rankings of archived years (about 60% of a recent year) now live in their own table. They are read when you open a year's Event Statistics or the all-time Event Statistics, with a short loading state and a Retry button if a read fails. A year whose statistics are not loaded yet shows its event count, never "Not recorded".
- Measured on a long reality (57 archived years): the database went from 540 MB to 145 MB, startup reads from about 500 MB to 78 MB, and loading took about half the time.
- Exports keep the same file format: event statistics are joined back in.

## First launch: one-time upgrade

- The first time this version opens an existing save it creates a recovery copy ("Before storage format 9", in Backups), then converts every archived year and compacts the database. On a long reality this takes a minute or two, with progress on the loading screen.
- If the app is closed or fails during the upgrade, the next launch continues where it stopped. Nothing is lost: every year is verified after conversion.
- Older DraftSim versions cannot open a format 9 database (they ask you to update). To go back, restore "Before storage format 9" from Backups in the older version.

Not verified on Windows WebView2 before release; the upgrade was verified on a copy of a real 540 MB save.
