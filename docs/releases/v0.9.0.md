# DraftSim v0.9.0

## Tournament presentation and highlights

- Reuse team, region, role and champion artwork throughout Momentum, Meta Shifts, pools, awards, MVPs, recaps and offseason summaries. Team and player cards retain tournament roster context.
- Show actual player names and signed form in compact Momentum columns. Align champion roles beside tier changes.
- Expand Notable Games with Most Kills, Closest Kill Score, Biggest Momentum Swing and Largest Gold Lead alongside fastest, longest and comeback games. Each highlight links to its recorded game. Explain probability changes in percentage points; missing historical data remains unavailable.
- Show team strength directly in Swiss pairings. Keep both slots aligned; winners are green and losers red without extra badges or layout shifts.
- Label Latest Matchday with competition stage, round, bracket/group and pre-round Swiss record.
- Display Perfect KDA for recorded zero-death performances while preserving unknown and partial legacy statistics.

## Interface consistency

- Standardize interface typography on Inter; reserve Cinzel for the DraftSim wordmark.
- Filter the Rookie Class by multiple roles with position icons.
- Align New Season difficulty controls, separate Golden Road from the champion identity, and improve annual rookie/team spacing.
- Expand Franchise Timeline details at the left edge. Team names reveal details; team cards provide profile navigation.
- Fix player-card fallback for empty champion pools and focus handling when navigating from a team card.

## Compatibility and distribution

Existing saves remain compatible. Optional tournament region/play-in metadata is accepted without a SQLite migration. Historical identities and statistics are not reconstructed when absent. Simulation formulas are unchanged by these presentation updates.

The release workflow runs interface/simulation checks, builds Windows x64 NSIS and MSI packages, runs native tests and validates installed NSIS navigation, reopen and upgrade from the pinned 0.6.0 installer before publishing. The MSI is built and distributed; installation smoke uses NSIS.

Installers: `DraftSim_0.9.0_x64-setup.exe` and `DraftSim_0.9.0_x64_en-US.msi`.

Local release validation: 1,404 unit tests, 56 browser tests, 12 native tests and six version-tool tests passed. Lint, types, production export and dependency audit passed (zero reported vulnerabilities).
