# DraftSim v1.14.0

Lighter saves for long bulk simulations, new event and SS statistics views, and a set of fixes for legacy and same-named data.

## Bulk simulation

- **Event archives are smaller.** Event Statistics records use a version 2 format that stores only the players that changed at each checkpoint, about 37% smaller per year. Existing version 1 records are read unchanged, and no migration or save rewrite is needed.
- **Desktop saves write only new history.** Archiving a year no longer re-encodes and resends every earlier year, which cut the history data sent for a 30-year run from about 304 MB to about 20 MB in a disposable measurement.
- The bulk loop yields to the interface before archiving and before saving each year, and cancellation behaves as before.
- Root and segment error screens now show a readable message with a copy-details button.
- The bulk results feed shows an **Event Statistics** summary per year: the top player per role and the most picked and most banned champion of each event, or "Not recorded" for legacy years.

## Statistics and SS

- **All-time Event Statistics** in the Hall records tab: per-role rankings and champion boards across archived years, with event, region and year filters, and a selector for the selected history or all loaded realities.
- **SS records:** longest streaks, most SS seasons, SS by team and region, and a timeline to compare players. The player career shows the longest SS streak.
- SS Race shows games progress instead of repeated requirement notes early in a season, role leaders in Event Statistics are more compact, and vacant seats take one line.
- Player names in SS Race and Event Statistics can be focused with the keyboard to open their hover cards.
- Roster Moves explains that AI offseason moves are resolved when you advance to the next year.

## Fixes

- Player form uses the team actually on each side after a side swap, and a manual game updates form once.
- The Playoffs and Regular scopes no longer include play-in games, and same-named teams are told apart by recorded participants, or left unknown.
- Imported event records are checked for impossible totals.
- Legacy games without recorded participants no longer credit the entrant roster for MVP, All-Pro, tournament player leaders or team grades. They stay unknown, so some old saves show fewer leaders or "unknown" grades.
- International title badges and academy counts respect region and stable team ids. SS selection ignores samples against opponents without a recorded roster.
- Completed stages keep per-pick KDA when a desktop save is slimmed, so event archives built after a restart keep their KDA totals.

## Compatibility

No SQLite schema change. An export made with this version contains version 2 event records and cannot be imported into v1.13.

Local verification: TypeScript, ESLint, the unit suite, the production export and the full browser suite passed. The bulk-simulation changes were measured with synthetic data and not exercised on Windows WebView2. The tagged workflow additionally runs the installer checks before publishing NSIS, MSI, deb, rpm and AppImage packages.
