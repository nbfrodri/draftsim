# DraftSim v1.14.1

Safer saves during long bulk simulations, a crash log for diagnosing a blank window on Windows, and Event Statistics and SS interface improvements.

## Bulk simulation on Windows

- **Saves are lighter during a bulk run.** Debounced saves are held while a bulk simulation runs, so only one save per simulated year is written instead of one at every slow match. Large values are sent to the native side in chunks of at most 1 MiB, inside the same SQL transaction and in the same order, so no single message carries a multi-megabyte JSON string. There is no schema change or migration.
- **A memory guard pauses the bulk** with a resumable message when the JavaScript heap approaches its limit, instead of letting the window go blank. The threshold (85%) is a first estimate.
- **Crash log.** Bulk runs write stage breadcrumbs (year, stage, JS heap, save size, no names or save contents) to `%APPDATA%\app.draftsim.desktop\logs\bulk-diagnostics.log`, written before each heavy step so it survives a renderer crash. If the previous session ended unexpectedly during a bulk run, the next launch shows a notice with a **Copy log** button. Backups > Save performance diagnostics also exports the log.
- Measurements were made on Linux with synthetic data. This release was not verified on Windows WebView2, so whether the blank window is gone is still to be confirmed; the log will show the year and stage if it happens again.

## Event Statistics

- **Choose the event in two steps:** event chips (Winter, Spring, Summer, First Stand, MSI, Worlds, Global Cup), then region chips with logos for domestic splits only. The selection is shown as text, for example "LCK · Spring Split".
- **Role leaders are stacked** as one card per role, like the SS Race, with team logos, performance score and supporting stats.
- **Rank movement arrows now appear.** The chip compared the current standings with a checkpoint that already contained them, so it was always empty or "no movement"; it now compares with the previous different standings.
- The champion statistics "Show: Top 10 / All" selector uses the same themed dropdown as the other filters.
- SS records and the all-time Event Statistics show role icons and team logos.

## SS

- The cyan **SS badge** replaces the plain letters "SS" in titles, labels, tables, hover cards and the career and history views, and scales with the surrounding text.
- Long player names are truncated in the SS Race instead of overlapping other text.

No save or schema change: existing realities and archives open as before. Games saved before this release keep their data; nothing is rewritten.

Local verification: TypeScript, ESLint, the unit suite, the native Rust tests, the production export and the full browser suite passed. The tagged workflow additionally runs the Windows and Linux installer checks before publishing NSIS, MSI, deb, rpm and AppImage packages.
