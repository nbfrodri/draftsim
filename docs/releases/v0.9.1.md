# DraftSim v0.9.1

- Latest Matchday headings now show bundled region logos for domestic competitions and event logos for First Stand, MSI, Worlds and Global Cup.
- International event identity is captured from the simulated phase, so the logo does not incorrectly come from the first participating team's region.
- Reverse Sweep and other result tags share the centered phase/round badge row above the score, keeping team names and scores aligned.

These are presentation changes. Matchday summaries remain transient; no save migration is required.

Windows x64 installers: `DraftSim_0.9.1_x64-setup.exe` and `DraftSim_0.9.1_x64_en-US.msi`.
