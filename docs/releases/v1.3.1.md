# DraftSim v1.3.1

## Consistent view loading

- Continuing a reality or season shows the centered DraftSim loading screen with a spinner while the dashboard interface loads.
- Setup screens, series, tournaments, libraries, the Hall and Realities use the same fallback, replacing the plain top-left `Loading...` paragraph.
- The fallback reuses the existing startup/closing shell and its accessible loading status. It disappears when the requested view is ready; views still load on demand.

Browser regressions hold view-code downloads to inspect the loading screen at the 1024px desktop minimum width, then release them and verify Continue playing and Realities navigation completes. This is a presentation change with no save migration or change to simulation behavior.

## Documentation

The English and Spanish READMEs and the systems, interaction, domain and Title Playground references describe current loading and the shared teammate rosters/results introduced in [v1.3.0](v1.3.0.md).

Windows x64 installers: `DraftSim_1.3.1_x64-setup.exe` and `DraftSim_1.3.1_x64_en-US.msi`. The [release workflow](../../.github/workflows/release.yml) publishes both after automated checks pass.
