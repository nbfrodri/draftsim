Outlook captures can be reproduced with `PLAYWRIGHT_CHANNEL=msedge npm run test:e2e -- e2e/roster-outlook.spec.ts` after building. The Live and Hall search captures come from `live-player-backups.spec.ts` and `history-timeline-honors.spec.ts`. In PowerShell, set `$env:PLAYWRIGHT_CHANNEL='msedge'` before running the command.
